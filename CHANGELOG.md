# Changelog

All notable changes to **Current Window Ports** are documented here.

## 0.1.0

Initial release.

- Status bar item listing the ports this window's own terminals are listening on
- Process-tree scoping, so servers from other VS Code windows stay out of the list
- One-click actions: open in browser over `https://`, open with `http://`, copy URL, kill process
- Settings for default protocol, poll interval, and hiding the item when no ports are open
